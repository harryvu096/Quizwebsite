## 🔴 Weak Points — Current State

### A. Content / Data (sab se bara masla)

1. **Answer-position smell — 76/136 banks mein ≥60% answers index 0 par hain (bohat si banks 100%)**
   Overall distribution: **56% / 29% / 13% / 2%**. Runtime `shuffle()` UI bacha leta hai, magar ye
   batata hai ke banks bulk-generated hain (correct answer hamesha pehle likha gaya). Distractors
   ki quality suspect hai — human spot-check zaroori hai. Koi bhi future feature jo bina shuffle
   print/share kare (revision sheet, PDF), us mein answers leak ho jayenge.
2. **8 duplicate question texts** (alag banks mein same question).
3. **Explanations bohat short hain** — median sirf 40 characters. "Why" exam-prep ka core value hai.
4. **Content depth kam** — har exam bank ~30 MCQs (3 levels × ~10 + boss). VU paper pattern ke liye patla.
5. **Marketing numbers inconsistent** — title "50 Subjects", meta/og "2000+ MCQs", README header
   "50 subjects · 3,322", UPDATES "68 · 4,152". Asal: **68 subjects, 4,152 MCQs**. Trust kharab hota hai.

### B. Product / Feature Gaps

6. **Leaderboard fake hai** — `profile.lb` sirf localStorage mein hai. Student "Leaderboard"
   bolega to real competition expect karta hai; ye sirf apne device ke scores hain. Misleading.
7. **Mock Exam (VUtes-style) complete hai magar hidden** — index.html mein commented out. 40% built feature bekaar.
8. **Cloud sync nahi** — device change par Export/Import manual hai. Students phone switch karte hain.
9. **Mistake Vault mein spaced repetition nahi** — 60 mistakes cap, koi review schedule, koi
   topic-weakness analytics nahi.
10. **Koi analytics nahi** — pata hi nahi ke students kya use karte hain (page views, drop-off, hardest MCQs).

### C. Bugs / Code Debt (abhi bhi zinda)

11. **`resetProgress()` incomplete** — "Reset ALL progress" khta hai magar `profile.mistakes`,
    `profile.totalScore`, `profile.cppSolved`, English Lab progress **reset nahi hote**.
12. **Native `alert()`/`confirm()`** — app.js 6, english.js 2, compiler.js 1. Polish todte hain.
13. **Dead code** — `clearVault()` mein `document.getElementById("goQuote");` (useless statement).
14. **`escape()` quotes escape nahi karta** (`>` / `"` / `'`) — attribute context mein kabhi
    breakout possible. `pName()` raw `innerHTML` mein jaata hai (self-XSS hardening item).
15. **Version drift** — index.html `?v=ahw9` vs english.js `?v=ahw11`; SW comment "v10" vs cache `v11`.

### D. Privacy / Security

16. **Personal phone number public** (`0347-0675100`) — index.html (footer, contact modal) +
    `AHW_SUPPORT_WA` in app.js. Spam/SMS-harassment risk. Best: Google Form / email.
17. **C++ Lab student code third parties ko jaata hai** (Judge0 CE, Wandbox, godbolt, emkc) +
    public CORS proxies (`corsproxy.io`, `allorigins.win`). Privacy + reliability risk;
    proxies beech mein code padh sakte hain.

### E. Performance

18. **`data/mcqs.js` 742 KB render-blocking `<script>`** — low-end phones / slow 3G par first
    interaction late. Per-subject lazy load possible (file:// compatibility tradeoff ke sath).
19. **`standalone.html` 1 MB** — har update par rebuild, CDN cache stale risk (build self-heal
    workaround already hai — ye symptom hai, solution nahi).

### F. Accessibility

20. **`prefers-reduced-motion` support nahi** — confetti/animations hamesha on.
21. **10.5–11px text** kai jagah (soon-badge, cert labels, mock legend) — mobile par unreadable.
22. **Modals mein `role="dialog"` / `aria-modal` / focus-trap nahi** (Esc/backdrop fix ho chuka, ye nahi).
23. Word Search drag interaction keyboard-only users ke liye mushkil.

### G. SEO / Discovery

24. **`robots.txt`, `sitemap.xml`, canonical, structured data (JSON-LD) nahi** — GitHub Pages live
    hai magar Google discoverability weak.
25. Stale meta numbers (upar #5) — social share preview bhi purana claim dikhaata hai.

### H. Repo / Engineering

26. **No LICENSE, .gitignore, package.json, tests, CI** — `tools/build.js` validator hai magar
    koi automated check nahi (GitHub Actions 15 min ka kaam).
27. `data/mcqs.json` + `data/mcqs.js` dono git mein (1.5 MB duplicate) — ek generated file
    `.gitignore` mein ho sakti hai.
