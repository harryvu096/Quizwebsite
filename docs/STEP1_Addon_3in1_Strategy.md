## 2. 3-in-1 ke Faide (Tumhari Soch Bilkul Sahi Hai)

### A) Session Time 2x — 3x
- Single Screw Game: Avg session = 8 - 12 min, phir bore
- 3-in-1 Park: Player Screw mein bore ho to 1 tap mein Restaurant par jaye, phir Arrow par — **Avg session 18 - 25 min**

### B) Ad Impressions Double
| Mode | Ads per Session | eCPM (Pakistan) | Earning per 1000 users |
|------|----------------|-----------------|------------------------|
| Single Game | 3-5 ads (1 interstitial per 3 levels + 1 rewarded optional) | $2 - $4 | $8 - $15 |
| **3-in-1** | **7-12 ads** (har world ka alag timer, bore nahi lagega) | $2 - $4 | **$18 - $35** |

**Monetization Trick:** Har game ka ad timer alag. Player ko lagta hai ad kam hai, lekin total ads double!

### C) Retention +30-50% Increase
- Day 1 retention single puzzle: 25-30%
- 3-in-1 collection: **35-45%** — kyunki agar 1 puzzle pasand na aaye to dusra try karega, uninstall nahi karega.
- Day 7 retention: 12% → **20%** target

### D) Ek Economy, Triple Motivation
Coins, Gems, Skins sab 3 games mein SHARED:
- Screw game se coins kamao → Restaurant mein skin kharido → Arrow mein hint lo
- Yani player ko 3 jagah grind karna padta hai — **IAP + Rewarded ad demand 3x**

### E) Play Store Updates ka Faida
1 app = 1 Play Store listing, lekin 3 update waves:
- Launch: Screw World (50 levels)
- Update 1.1: + Restaurant World (app update → Play Store boost)
- Update 1.2: + Arrow World (phir boost)
→ Har update Play Store algorithm mein "What's New" bump deta hai.

## 3. Khatre (Agar Ghalat Kiya To)

| Khatra | Solution |
|--------|----------|
| **App Size >150MB → Install drop 40%** | Unity mein 3 games ka shared code + assets compress → Target **AAB <60MB** (har world <15MB) |
| **User Confuse: "Yeh game hai kya? Screw ya Arrow?"** | Home par Theme Park map — 3 alag gates, clear icons, tutorial sirf 1st world se start |
| **Development 3x time (6-9 weeks vs 3 weeks)** | **Phased Launch:** MVP sirf Screw (3 weeks mein live), phir 2 worlds update se add |
| **ASO Dilution: Title mein 3 keywords fit nahi** | Title: **Bolty's Puzzle Park: Screw, Sort & Arrow** (50 char limit mein 3 keywords) |
| **Ad Spam → 1-star reviews** | Rule: Interstitial sirf WORLD FAIL par, max 1 per 3 min. Rewarded hamesha optional. |
| **Google Policy: Deceptive?** | Nahi, jab tak icon/screenshots mein clearly 3 games dikhao aur description mein likho "3 Games in 1 App" |

## 4. Recommended Architecture: "Theme Park" Model (Best Practice)

```
HOME: BOLTY'S PUZZLE PARK 🎪
│
├── 🎨 Hub World (Park Map)
│   ├── Daily Spin Wheel (shared)
│   ├── Coin Shop (shared)
│   ├── Daily Missions: "Screw mein 5 levels + Restaurant mein 3 orders + Arrow mein 1 escape"
│   └── Streak Calendar (shared)
│
├── 🔩 WORLD 1: Screw Rescue (MAIN — 50 levels at launch)
│   ├── Core: Screw sort to rescue Bolty robot
│   ├── Difficulty: Easy → Hard (levels 1-50)
│   └── Boss: Giant Locked Vault (every 10 levels)
│
├── 🍕 WORLD 2: Sort & Serve (UNLOCK at Level 10 or Update 1.1)
│   ├── Core: Color plates sort → customer serve
│   ├── Twist: Timer + combo
│   └── Boss: Rush Hour (100 customers in 60 sec)
│
└── ➡️ WORLD 3: Arrow Escape (UNLOCK at Level 20 or Update 1.2)
    ├── Core: Rotate arrows → guide king to exit
    ├── Twist: Lasers, portals after level 30
    └── Boss: Maze Master (biggest maze)
```

**Player Flow (30-sec loop per world):**
30 sec Screw → Win → 10 coins → "Try Restaurant World?" popup (optional) → Player switch → Ad only on fail → Daily mission progress shared → Return to Hub

**Economy Shared:**
- Coins: All 3 worlds se milte hain
- Gems: Daily missions + IAP
- Hearts: Har world ke alag hearts (to force world switch, not quit app)

## 6. Final Recommendation: Phased 3-in-1

**OPTION A (RECOMMENDED): Phased Launch — Best for Solo Dev**
- **Week 1-3:** Build & Launch **Screw World only (50 levels)** — App size 35MB, jaldi Play Store live, ASO test
- **Week 4-5:** Update 1.1 → **Add Sort & Serve World (30 levels)** — Play Store "Updated" boost + re-engage users via push
- **Week 6-7:** Update 1.2 → **Add Arrow Escape World (30 levels)** — Final 3-in-1 complete (110+ levels total)
- **Faida:** Jaldi earning start, har update par downloads spike, bug risk kam

**OPTION B: Day-1 Mega Launch — Agar Team/ Time Hai**
- 3 Worlds ek sath (110 levels) — 6-7 weeks build, AAB ~55MB, marketing mein "3 Games in 1!" hook zyada powerful
- Faida: TikTok par "1 app mein 3 games!" viral angle tez, Day 1 hi long session

**Meri Advice:** **Option A lo** — tum solo ho, jaldi market mein aana zyada important hai. Screw game se hi 2 hafte mein pata chal jayega downloads aa rahe hain ya nahi, phir 2 worlds add karna safe hai.
